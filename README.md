# WayPoint

Mapa com rotas a pé e relatos recentes de segurança enviados pela comunidade, com moderação antes de publicar e sem identificar quem enviou.

Global Solution 2026/2 · FIAP · tema CitizenTech, linha Cidades · ODS 11 e ODS 10.

## Tecnologias

- React 19 + Vite + TypeScript
- Tailwind CSS 4
- React Router

## Como rodar

```bash
npm install
npm run dev
```

A aplicação abre em http://localhost:5173.
